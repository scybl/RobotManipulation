# RobotManipulation

[中文](README.md)

RobotManipulation is a ROS 2 Humble manipulation workspace that combines two simulator demos: `PickPlace` and `ShapeSorting`. It covers point-cloud perception, target localisation, MoveIt motion planning, gripper control, scene rescanning, shape recognition, and sorted placement.

External spawner package names are retained only for simulator interface compatibility. Owned ROS packages use functional names: `pick_place_solution` and `shape_sorting_solution`.

![RobotManipulation preview](docs/images/manipulation-preview.svg)

## Features

| Module | Capability |
| --- | --- |
| `PickPlace` | Filters table point clouds, localises targets and baskets, then plans grasp/place actions |
| `ShapeSorting` | Recognises nought/cross objects, estimates poses, registers obstacles, and sorts objects |
| Motion planning | Uses MoveIt pose goals, Cartesian approach/retreat paths, and fallback planning |
| Robustness | Uses rescanning, retries, placement offsets, and return-home behaviour for simulator timing variance |
| Entry points | Root `scripts/run_project.sh` forwards to both demos; `summary` mode is ROS-free |

## Runtime Views

PickPlace starts with point-cloud capture, estimates the object pose, plans the MoveIt grasp, and places the object into a basket.

## Quick Start

ROS-free project summary:

```bash
bash scripts/run_project.sh summary
```

Build and run PickPlace:

```bash
cd PickPlace
bash scripts/setup_environment.sh
bash scripts/run_demo.sh launch
```

Build and run ShapeSorting:

```bash
cd ShapeSorting
bash scripts/setup_environment.sh
bash scripts/run_demo.sh launch
```

You can also use the root entry point:

```bash
bash scripts/run_project.sh pick-place launch
bash scripts/run_project.sh shape-sorting launch
```

Trigger simulator scenarios:

```bash
bash scripts/run_project.sh pick-place task 1
bash scripts/run_project.sh pick-place task 2
bash scripts/run_project.sh pick-place task 3
bash scripts/run_project.sh shape-sorting task 1
bash scripts/run_project.sh shape-sorting task 2
bash scripts/run_project.sh shape-sorting task 3
```

## Requirements

- ROS 2 Humble
- MoveIt
- Gazebo
- PCL, TF2, and ros2_control dependencies
- Matching world spawner simulator packages: `PickPlace` depends on `cw1_world_spawner`, `ShapeSorting` depends on `cw2_world_spawner`. **Both are private course assets not included in this repository** and are not publicly obtainable; this repo is therefore positioned as a code-architecture/implementation showcase, not a guaranteed out-of-the-box simulator reproduction for third parties. Reproducing the demos requires implementing or substituting an equivalent world-spawner node.

## Data Notes

The project uses simulated scenes and local shape assets. It does not require an external dataset. `ShapeSorting/src/shape_sorting_solution/data/` contains nought/cross STL and PCD reference assets. Full runs require a local ROS 2 and simulator environment.
